# The Level-Six Fibre Lattice in Engel's Torus Fibration

Raeez Lorgat

The note determines the monodromy-invariant integral structures in Engel's smooth-fibre lattice `H_1(F,Z)`. It reconstructs the two geometric markings and proves `iota_delta0 xi = -6 psi`. The resulting alternating form has type `(1,6)`. Its discriminant pairing defines a finite Heisenberg group and an irreducible six-dimensional representation.
